🚀 CÓMO USAR
═══════════════════════════════════════════════════════════════════════════════

1. COMPILAR:
   $ mvn clean compile

2. EJECUTAR DEMO:
   $ mvn exec:java -Dexec.mainClass="com.nttdata.enterprise.orchestration.AutomationOrchestrator"

3. CREAR JAR:
   $ mvn clean package

4. EJEMPLOS DE CÓDIGO:

   // Crear orquestrador
   AutomationOrchestrator orchestrator = new AutomationOrchestrator();
   
   // Crear solicitud de pruebas
   UserRequest request = new UserRequest();
   request.setRequestType("test-execution");
   request.setBrowser("chrome");
   request.setEnvironment("staging");
   Map<String, Object> params = new HashMap<>();
   params.put("profile", "regression");
   request.setParameters(params);
   
   // Procesar solicitud
   CompletableFuture<Map<String, Object>> result = orchestrator.processRequest(request);
   Map<String, Object> response = result.get();
