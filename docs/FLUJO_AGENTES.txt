╔══════════════════════════════════════════════════════════════════════════════╗
║                        INTERCONEXIONES DE AGENTES                            ║
╚══════════════════════════════════════════════════════════════════════════════╝

Típicamente, los agentes se usan en este orden:

┌─────────────────────────────────────────────────────────────────────────────┐
│ FLUJO 1: CICLO COMPLETO DE PRUEBAS                                         │
├─────────────────────────────────────────────────────────────────────────────┤
│ 1. TestPlanningAgent    → Genera plan de pruebas                            │
│ 2. TestDesignerAgent    → Diseña escenarios y datos                         │
│ 3. TestExecutionHandler → Ejecuta las pruebas                               │
│ 4. JiraTaskAgent        → Publica resultados en Jira                        │
│ 5. GitHubActionsAgent   → Dispara pipeline con resultados                   │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│ FLUJO 2: EJECUCIÓN RÁPIDA                                                   │
├─────────────────────────────────────────────────────────────────────────────┤
│ 1. TestExecutionHandler → Ejecuta pruebas                                   │
│ 2. JiraTaskAgent        → Publica resultados                                │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│ FLUJO 3: PLANIFICACIÓN Y DISEÑO                                             │
├─────────────────────────────────────────────────────────────────────────────┤
│ 1. TestPlanningAgent    → Genera plan                                       │
│ 2. TestDesignerAgent    → Diseña escenarios                                 │
│ 3. GitHubActionsAgent   → Crea PR con escenarios                            │
└─────────────────────────────────────────────────────────────────────────────┘
